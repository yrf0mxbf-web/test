Советы по Strovo

🧱 Строительство

  • Начинай с простых форм — кубов, лестниц, платформ
  • Используй разные материалы для текстур
  • Добавляй источники света для атмосферы
  • Экспериментируй с временем суток

🚀 Публикация

  • Сохраняй проект перед публикацией
  • Придумай креативное название
  • Проверь, что всё работает в режиме просмотра
  • Делись ссылкой с друзьями!

💡 Лайфхаки

  • ПКМ + движение мыши — вращение камеры
  • Колесо мыши — приближение/отдаление
  • Светящиеся блоки отлично смотрятся ночью
  • Стекло можно использовать для воды и окон
