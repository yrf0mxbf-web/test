STROVO — переделан в стиле Roblox 2016
=====================================

Что изменено:
- Полностью новый CSS (светлая тема, синий хедер #00A2FF, зелёные кнопки Play)
- Классический header как в Roblox 2016
- Страницы index, games, shop, login, signup, profile и др. переписаны
- Убрана современная тёмная тема и сайдбар
- Сохранён Python-сервер (server.py) и данные

Как запустить:
1. Установи зависимости: pip install flask flask-cors
2. cd strovo
3. python server.py
4. Открой http://localhost:5000 (или порт из server.py)

Клиент (Strovo-Setup.exe) нужно взять из оригинального архива и положить в strovo/downloads/

Стиль вдохновлён официальным сайтом Roblox образца 2016 года.
